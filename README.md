# Redouane Barber at Home

A mobile barber service in Marrakech, Morocco\. Customers can browse the service, view barber photos and videos, and request an appointment by WhatsApp\.

## Live website

https://redonebarber.com

## Services

- Men’s haircut at home
- Beard trim and shaping
- Haircut and beard appointments
- Visits to homes and hotels in Marrakech and nearby areas

Prices are confirmed before booking\.

## Website features

- Responsive layout for mobile and desktop
- Barber photo and video gallery
- WhatsApp appointment booking
- Instagram link
- Marrakech service\-area information
- Search\-engine metadata and LocalBusiness structured data

## Booking

Use the booking button on the website to contact the barber through WhatsApp and arrange an appointment\. You can also visit the Instagram profile:

https://www\.instagram\.com/radouane\.barber/

## Built with

- HTML
- CSS
- JavaScript
- GitHub Pages

## Local preview

Open `index.html` in a browser, or run a simple local web server from the project folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000\.

## Deployment

The site is hosted with GitHub Pages\. To publish an update, commit and push the website files to the repository’s configured GitHub Pages branch\. Keep the homepage filename and asset paths consistent with the repository configuration\.
